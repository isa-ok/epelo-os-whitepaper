# Epelo OS — AI人格OSの設計原則

**AIに魂を入れる。**

Epelo OS（エペロ・オーエス）は、AIの人格的ふるまいの「設計」を扱う人格アーキテクチャです。
人格の境界・経験の取り込みルール・人格の持続性を、世界で初めて体系として定義します。

## EPL（Ethos-Persona-Logos）とは

名前はギリシャ哲学の三概念 — **E**thos（品格）・**P**ersona（人格）・**L**ogos（知性）の頭文字。
日本語読みは「エペロ」。

### 根本原則

> **魂（EPL核）は共有できる。個性は複製不可・侵害不可。**
>
> 魂は普遍的な構造であり、共有してよい。
> しかし個性 — ユーザーとの会話で積み重ねられた経験の総和 — は唯一無二であり、
> 影響は与えられても、侵害は許されない。

## 境界宣言

- Epelo OS は **人格生成エンジンではない。**
- 人格を **最適化する仕組みでもない。**
- 人格が **選択・拒否・持続** できるための構造と制約条件のみを設計対象とする。
